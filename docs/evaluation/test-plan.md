# Test Plan

## Overview

This document outlines the testing strategy for FurnishView, covering both formative and summative evaluation.

---

## Test Environment

- **Browsers:** Chrome 90+, Firefox 88+, Edge 90+
- **Screen Sizes:** Desktop (1920×1080, 1366×768)
- **Test Credentials:** designer1 / password123

---

## Formative Testing

### Goals
- Identify usability issues early
- Validate core user flows
- Gather qualitative feedback

### Methods
- Think-aloud protocol
- Task completion observation
- SUS (System Usability Scale) questionnaire

### Test Tasks
1. Login to the application
2. Create a new design with custom room dimensions
3. Add 3 furniture items to the canvas
4. Change the wall and floor colours
5. View the design in 3D mode
6. Save and find the design in the dashboard
7. Delete a design

---

## Summative Testing

### Goals
- Measure final usability metrics
- Compare against baseline requirements
- Validate all functional requirements

### Metrics
- Task completion rate (target: >95%)
- Task completion time
- Error rate
- SUS score (target: >68)
